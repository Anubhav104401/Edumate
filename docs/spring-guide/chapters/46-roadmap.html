Becoming a pioneer: capstone projects and a learning path

Reading makes things familiar; building makes them yours. These projects extend EduMate in realistic ways, each touching several chapters. They are graded from a few hours to a few days. Do them on a branch, with tests.

Level 1 and 2 projects: foundations and data

#ProjectYou practise
1Book details and reservations. GET /api/library/books/{id}; POST /api/library/books/{id}/reservations for students (at most one per book, only when no copy is available); a Flyway migration for the book_reservation table.controllers, validation, error codes, entities, derived queries, migrations, RoleMatrix
2Medical exemption requests. Students upload a request; exam superintendents approve or reject it; approved ones change hall-ticket eligibility (rule R2).a small workflow on an entity, @Transactional, object-level security, integration tests
3A paged, filtered audit search with Page<T>, sorting and date ranges.Pageable, JPQL with optional filters, DTO projections
4Timetable room capacities. A capacity column for rooms and a clash when a section is larger than the room.expand/contract migrations, domain rules, updating a solver with tests

Level 3 projects: production

#ProjectYou practise
5Overdue-book reminders. Every morning at 7:00, queue one e-mail per overdue loan (at most one per day per loan).@Scheduled(cron), the outbox, deduplication keys, a fixed Clock in tests
6Refresh tokens. Short-lived access tokens (15 minutes) plus a refresh endpoint and server-side revocation of refresh tokens.Spring Security, JWT claims, a token store, security tests
7Metrics that matter. Expose Prometheus metrics; add counters for payments (succeeded, failed, duplicates ignored) and a timer for result computation; build a Grafana dashboard.Actuator, Micrometer, the Observation API, securing management endpoints
8Testcontainers. Add a PostgreSQL + Redis Testcontainers set-up with @ServiceConnection and run the cache tests against real Redis.integration testing with real infrastructure
9ProblemDetail errors. Migrate the error format to RFC 9457 behind a setting, keeping the old format for the current frontend.@RestControllerAdvice, content negotiation, backward compatibility

Level 4 projects: pioneer

#ProjectYou practise
10An audit starter. Extract EduMate's audit log into edumate-audit-spring-boot-starter with properties, back-off, configuration metadata and ApplicationContextRunner tests; use it from EduMate.auto-configuration internals
11Events and Modulith. Replace direct cross-module calls (attendance → notifications, results → notifications) with events; add Spring Modulith, fix the two module cycles, make verify() pass, and generate the module diagrams.events, transactional listeners, module boundaries
12A real SMS gateway behind the NotificationGateway interface, using an HTTP interface client with timeouts, retries and a concurrency limit, tested with WireMock.HTTP clients, resilience, conditional beans
13Virtual threads under load. Write a k6 or Gatling test for "results morning"; compare platform and virtual threads, with and without the cache; explain the results with metrics.performance engineering
14A native payment-callback service. Split the payment callback into a tiny Spring Boot application, build it as a GraalVM native image, and add the runtime hints it needs.AOT, native images, service boundaries
15Your own BeanPostProcessor or aspect that enforces a rule of your choice (stateless services, no controller calls a repository directly) and fails start-up or a test when it is broken.the container's extension points, architecture tests

How to keep learning

  • Read the reference documentation of Spring Framework and Spring Boot. It is long, precise and excellent; read a section after each chapter of this course.
  • Read the source. In your IDE, jump into DataSourceAutoConfiguration, TransactionInterceptor, JpaRepository's implementation SimpleJpaRepository, or DispatcherServlet.doDispatch. The framework's code is readable and well commented; debugging into it is the fastest way to go from user to expert.
  • Follow the releases: the Spring blog, the "This Week in Spring" posts, and the release notes of each minor version.
  • Certify, if useful for you: the Broadcom/VMware Spring Certified Professional exam covers the container, AOP, data, transactions, MVC, security, Boot and testing: the first four levels of this course.
  • Contribute: documentation fixes and issues with small reproducible examples are welcome in the Spring projects, and are how many Spring experts started.
What "pioneer" means Not knowing every annotation, but being able to answer any "why does Spring do this?" by reasoning from a few ideas: beans and dependency injection, conditions and auto-configuration, proxies and interceptors, the persistence context, the filter chain, and transactions. Everything else in the framework is built from those.
