The frontier: what is new in Spring Boot 4 and Spring Framework 7

EduMate is built on the newest generation of Spring. This chapter lists what changed in that generation, shows where EduMate already relies on it, and explains how to migrate an older application. Versions move quickly: for details, always check the release notes of the exact version you use.

A modular Spring Boot


Spring Boot 4 split its large auto-configuration jar into many focused modules, each with its own starter. You add
exactly the technologies you use, the classpath shrinks, and conditions have less to evaluate. EduMate's
pom.xml uses the new names:

Migrating an older application


    

  1. Get to the latest 3.x first (3.5), fix every deprecation warning there, and make sure the test suite is
green. Deprecated APIs in one generation are usually removed in the next.
    2. 

  2. If coming from Boot 2: first move to 3 (Java 17, javax.* → jakarta.*,
SecurityFilterChain beans instead of WebSecurityConfigurerAdapter,
requestMatchers instead of antMatchers).
    3. 

  3. Use the properties migrator: add spring-boot-properties-migrator as a runtime dependency
for one run; it reports and temporarily maps renamed properties at start-up. Remove it afterwards.
    4. 

  4. Automate the mechanical parts: OpenRewrite recipes can update dependencies, starters, imports and
common API changes across a code base.
    5. 

  5. Change the parent version, switch to the new starter names, and fix compilation: Jackson 3 packages,
moved test annotations, removed deprecated APIs.
    6. 

  6. Run everything: unit and integration tests, then a manual smoke test of the main flows; watch the
start-up log for warnings.
    7. 



Stay current in small steps
Spring Boot releases a minor version about every six months and supports each for a limited time. Upgrading every
release (a routine, tested change) is far cheaper than a big jump every few years. EduMate's test suite, including the
PostgreSQL compatibility and security coverage tests, is what makes such upgrades safe.



Self-check


Why did EduMate's starters change names compared with older tutorials?

Spring Boot 4 modularised auto-configuration into focused modules with matching starters, for example
spring-boot-starter-webmvc instead of spring-boot-starter-web.


How do you recognise Jackson 3 code?

Its packages start with tools.jackson instead of com.fasterxml.jackson (the annotations
package is the exception and remains compatible).


What is the safest order for a major upgrade?

Latest minor of the current generation first, remove deprecations, green tests; then change the major version,
using the properties migrator and automated recipes, and test again.
