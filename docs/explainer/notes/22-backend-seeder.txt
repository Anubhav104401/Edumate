=== FILE backend/src/main/java/com/edumate/config/DemoDataSeeder.java
>>> SUMMARY
Fills an **empty** database with **demonstration data**, so every screen has something to show the moment EduMate starts. It runs only when `edumate.demo.seed` is `true` (the dev and docker profiles) **and** the database has no users yet. If you restart with data already present, it does nothing. In production the setting is false.

**What it creates:**
- the main campus **JGC** with three programmes (B.Tech CSE with 60 seats, M.Tech CSE with 18, MBA with 30);
- staff accounts for every role, and five teachers;
- five 5th-semester courses;
- four earlier exam sessions (with **published** history for semesters 1–4) and the current one;
- 60 students in sections A and B, with guardians;
- marks, fee demands and payments, library books and loans;
- a **published timetable** for both sections, made by the real solver;
- 32 admission applications, with placeholder scanned documents;
- a small second campus **CCC**, to show that campuses cannot see each other's data.

**Repeatable randomness.** `new Random(2026)` always produces the **same** sequence of "random" numbers. Every fresh start therefore creates exactly the same names, marks and payments, so screenshots, the README and this guide stay correct.

**Placed on purpose.** A few records are not random, so the report's test cases can be shown live:
- Aarav Sharma (23BTRCS007): grades S, A, B, B, C over credits 4, 4, 3, 3, 2 (**TC-013**), and his fee is not yet paid (**TC-005 / TC-006**);
- 23BTRCS003: an internal mark of 18 in DBMS, to be corrected to 22 (**TC-012**);
- Kiran Joshi (23BTRCS015): the SQA internal mark is missing (rule **R5**), which also blocks result computation until a teacher fills it in;
- Ishaan Verma (23BTRCS012): fees overdue;
- Rohan Gupta: a 17-year-old applicant who still needs guardian consent (**TC-020**).

**Every demo account's password is `Edumate@2026`.** The login page lists the accounts (see `DEMO_USERNAMES` in `frontend/src/config.ts`).

`placeholderPdf`: builds a **real, valid PDF** by hand. A PDF is text with numbered "objects":
- line 604: removes the characters `(`, `)` and `\`, which have special meaning inside PDF text;
- line 605: the page's drawing instructions: "BT … ET" = begin/end text, font size 16, position, then the two lines of text;

- line 626: turns the text into bytes (ISO-8859-1, one byte per character, so the positions are exact).
