=== FILE frontend/src/pages/exam/ConsolidatedReportView.tsx
>>> SUMMARY
**The consolidated marks table** of one result set: one row per student, one column per course (grade and marks), then SGPA, CGPA and PASS/FAIL, with a **"Download CSV"** button for spreadsheets.

This is exactly the report of **TC-017 / DEF-031**: it contains **every** student's marks, so only examination superintendents and administrators may load it. When a student tries, the backend answers 403 and records the attempt in the audit log. This component is used by both the results workflow page and the reports page.

**CSV safety.** The CSV comes from the backend, which puts a `'` in front of any cell starting with `=`, `+`, `-` or `@`. Spreadsheet programs would otherwise run such cells as formulas (*CSV formula injection*).
>>> 16
`downloadCsv`: saves the report as a file.
>>> 17-18
Fetches the CSV **with the login token** (as a Blob).
>>> 19-23
The usual way to make the browser save bytes as a file: make a temporary local address for them, create an invisible link to it with a `download` file name such as `consolidated-marks-5.csv`, and "click" it.
>>> 24
Releases the temporary address.
>>> 25-26
Any error (for example 403) becomes a toast.
>>> 30-32
While loading, show "Loading…"; on error, the red box; with no data, nothing.
