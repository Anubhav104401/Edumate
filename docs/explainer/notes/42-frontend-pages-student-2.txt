=== FILE frontend/src/pages/student/MyResultsPage.tsx
>>> SUMMARY
**"My results"**: every **published** semester, newest first. Each semester card shows the SGPA, CGPA, credits earned / registered, PASS or FAIL, when it was published, and a table of courses with marks, grade and grade points.

Only **published** results ever reach this page; the backend's query filters on PUBLISHED. On results morning thousands of students open this page at once, so the backend serves it from the **cache** (`@Cacheable("publishedResults")`, Redis in Docker) instead of asking the database each time.
>>> 13
The backend sends semesters oldest first; `[...data].reverse()` makes a **copy** and reverses it, so the newest comes first. The original data is left unchanged, because React state must never be changed in place.
>>> 15-20
The drawing: the title, loading, error, and "No results have been published yet." if the list is empty.
>>> 21-22
One card per semester.
>>> 23-26
The card's header: "Semester 5" and the exam session's name.
>>> 28-29
"Credits earned: 16 of 16 · 28 Sept 2026, 10:15 am".
>>> 32-34
The SGPA, always with two decimals (`toFixed(2)`: 8.6 → "8.60").
>>> 36-37
The CGPA, the same way.
>>> 42
Older history semesters (from the demo data) have no course details …
>>> 44-48
… otherwise a table of courses and its header row.
>>> 57-59
One row per course.
>>> 64
The grade cell: a red badge for F, green for anything else.
