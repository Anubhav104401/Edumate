=== FILE frontend/src/auth/AuthContext.tsx
>>> SUMMARY
**Remembers who is logged in** and makes that person available to every page through `useAuth()`.

- **Login:** `POST /api/auth/login` with `{"username": "...", "password": "..."}`. The backend answers `{"token": "eyJ…", "user": {...}}`. The token is saved in `sessionStorage` and sent with every later request.
- **Page refresh:** React's memory is wiped, but the token survived in `sessionStorage`. So on start-up, `GET /api/auth/me` asks the backend who the token belongs to, and the user is restored.
- **Logout:** the token is thrown away. The backend does not need to be told, because it keeps **no session**: every request carries its own proof (the token). Once the token stops being sent, the person is logged out. (The token itself stays valid until it expires after 8 hours, which is why it is kept only for the life of the tab.)
- **Expired token:** any 401 answer triggers a logout with the message "Your session has ended. Please log in again."

**React hooks used here, in one line each:**
- `useState`: a value that, when changed, makes React redraw;
- `useEffect`: code that runs after drawing (for example fetching data);
- `useCallback` / `useMemo`: keep the same function/object between draws, so child components are not redrawn needlessly;
- `createContext` / `useContext`: share a value with every component inside a provider.

=== FILE frontend/src/auth/RequireAuth.tsx
>>> SUMMARY
A **gate** in front of pages:
- not logged in → go to the login page, remembering where the person wanted to go, so the login page can send them back afterwards;
- logged in with the wrong role → show "You do not have access to this page.";
- otherwise → show the page.

The backend enforces the same rules again. This gate only saves people from opening pages whose data they could not load anyway.
>>> 19-20
The start-up check is still running: show "Loading…".
>>> 22-23
Nobody is logged in: go to `/login`. `replace` means the Back button will not return to the forbidden page, and `state={{ from: … }}` remembers the address they wanted.
>>> 25-26
Roles were given and the user's role is not among them: show the red "no access" message. The text is `t.errors.forbiddenPage` in `messages.ts`.
>>> 28
All checks passed: show the page. `<>…</>` is an invisible wrapper (a *fragment*).

=== FILE frontend/src/hooks/useLoad.ts
>>> SUMMARY
**The standard way a page fetches data.** Almost every page starts like this:
<pre class="block">const { data, error, loading, reload } = useLoad(() =&gt; api.fees.mine(), []);</pre>
- `loading` is true while waiting (the page shows "Loading…");
- `data` holds the answer when it arrives;
- `error` holds a friendly message if it failed (the page shows it in a red box);
- `reload()` fetches again (for example after saving something).

The second argument, `deps` ("dependencies"), lists values that should cause a **new** fetch when they change. For example, the marks page passes `[courseId]`, so choosing another course reloads the sheet.

**The "cancelled" trick.** If the person picks course A and then quickly course B, two requests are in flight. If A's answer arrives **after** B's, it would overwrite the screen with the wrong course. Each fetch therefore gets a `cancelled` flag, which is set when a newer fetch starts or the page closes, and a cancelled fetch's answer is ignored.

**Why a custom hook?** Without it, every page would repeat the same 25 lines of state, loading and error handling, and each copy could have its own small bugs. Libraries such as TanStack Query do this (and much more, such as caching). For EduMate's needs, this small hook is enough, and nothing needs to be installed.
>>> 12-17
What the hook returns: the data (or `null`), an error message (or `null`), the loading flag, `reload`, and `setData` (to replace the data directly, for example after a save returned the new version).
>>> 20
`useLoad<T>`: `loader` is the function that fetches; `deps` are the values that trigger a new fetch; `enabled = true` allows a page to hold off fetching until, say, a course has been chosen.
