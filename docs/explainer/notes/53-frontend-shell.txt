=== FILE frontend/src/components/TopLoader.tsx
>>> SUMMARY
**The glowing line along the top edge while EduMate waits for the backend**, the way YouTube and GitHub show loading.

`api/http.ts` counts the requests on their way. `useSyncExternalStore` lets React read that count safely and redraw this component when it changes. We cannot know how far along a request really is, so the line **creeps** towards 85% while waiting (fast at first, then slower and slower), then shoots to 100% and fades out when the last answer arrives.

It waits `LOADER_DELAY_MS` (150 ms) before appearing, so answers that come back quickly never make it flicker.

=== FILE frontend/src/components/charts.tsx
>>> SUMMARY
**Two hand-drawn charts**, made of SVG shapes and animated with motion:
- `<Ring>`: a **progress ring** (a "meter"): the attendance of each course, the overall attendance, the share of fees paid, the step of the welcome page's journey;
- `<TrendChart>`: a **line chart** of SGPA and CGPA, one point per semester.

**Why draw them by hand instead of using a chart library?** Both are small, and drawing them directly keeps full control of the look in both themes and keeps the app light (a general chart library adds 100 kB or more).

**The rules they follow** (from established data-visualisation practice):
- thin lines (2 px), a solid hairline grid in the background, never heavy boxes;
- two series → a **legend** is always shown; the values are written only at the **end** of each line (and only if the two labels would not overlap), never at every point;
- numbers are written in the normal **text** colours, never in the line colours (a light line colour is hard to read as text);
- the two line colours (`--chart-1` blue, `--chart-2` orange in `theme.css`) were checked with a colour-vision validator, so people with colour-blindness can still tell them apart, in light and in dark mode;
- a **read-out**: hover (or Tab to the chart and use ← →) and a vertical line snaps to the nearest semester, with a small box listing both values;
- every value is **also written as plain text** on the same page (the semester cards), so nothing depends on seeing the chart.

**How the ring works.** An SVG circle's outline can be drawn as a dash pattern. The dash is made exactly as long as the circle's circumference; then `stroke-dashoffset` slides that dash along, hiding part of it. Offset = circumference → nothing visible; offset = 0 → the full circle. Animating the offset from "all hidden" to "hidden except the percentage" draws the ring.
