=== FILE frontend/index.html
>>> SUMMARY
The **only HTML page** of the whole frontend. It is almost empty: a `<div id="root">` and one `<script>`. React fills that div with every screen of EduMate.

This is what "single-page application" (SPA) means. The browser loads this one page once. After that, moving from "Dashboard" to "My fees" does **not** load a new page from the server. React swaps the content inside the div, and only the data travels as JSON. That is why moving between screens feels instant.

The alternative is a multi-page site, where the server builds a new HTML page for every click (as Spring MVC with Thymeleaf templates would). That is simpler for small sites, but slower to use, and it mixes the look of the pages into the Java code. The report asks for a React SPA.

=== FILE frontend/vite.config.ts
>>> SUMMARY
Settings for **Vite**, the frontend's development server and build tool.

**The most important part is the proxy.** During development, two programs run:

| Program | Port | Job |
|---|---|---|
| Vite | 5173 | serves the React app to the browser |
| Spring Boot | 8080 | answers `/api/...` with JSON |

The browser talks **only** to port 5173. When the page asks for `/api/fees/me`, Vite forwards (proxies) that request to `http://localhost:8080/api/fees/me` and passes the answer back:

<pre class="block">Browser ──GET /api/fees/me──► Vite :5173 ──same request──► Spring Boot :8080
Browser ◄──────JSON──────── Vite :5173 ◄──────JSON─────── Spring Boot :8080</pre>

**Why not let the browser call port 8080 directly?** A different port counts as a different **origin** (origin = scheme + host + port). Browsers block a page from reading answers from another origin unless that server sends special **CORS** headers. With the proxy, the browser only ever sees one origin, so no CORS rules are needed. That is one less security setting to get wrong.

In production (Docker), **nginx** plays the same role on port 3000 (see `nginx.conf`), so the frontend code is identical in both cases: it always calls `/api/...` on its own origin (`API_BASE = ''` in `config.ts`).

=== FILE frontend/nginx.conf
>>> SUMMARY
Settings for **nginx** (say "engine-x"), the web server in the production-like Docker setup. It does two jobs:
1. serves the **built** React files (index.html, JavaScript, CSS) from `/usr/share/nginx/html`;
2. forwards every `/api/...` request to the Spring Boot container (`backend:8080`), exactly as Vite does in development.

It also adds **security headers** to every answer. These are the "defence in depth" fix listed for DEF-036 (reflected XSS). React already escapes text, so injected HTML shows up as harmless text; the headers are a second wall behind that one.

**Ports in Docker:** nginx listens on port 80 inside its container, and `docker-compose.yml` maps it to port **3000** on your computer. So you open http://localhost:3000.
>>> 7
One "server" block = one website.
>>> 8
Listen on port 80, the standard HTTP port, inside the container.
>>> 9
`_` means "answer whatever host name is used".
>>> 10
The folder with the built frontend files.
>>> 13
The largest request body nginx accepts. A 5 MB upload plus the multipart wrapping is slightly more than 5 MB, so the limit is 6 MB. nginx's default of 1 MB would block document uploads with error 413.
>>> 16
**Content-Security-Policy (CSP):** the browser may load scripts, styles and pictures only from this same site (`'self'`). Pictures may also come from `blob:` and `data:` (used to preview an upload before sending it). `object-src 'none'` forbids old plug-ins, and `frame-ancestors 'none'` forbids other sites from showing EduMate inside a frame. Even if an attacker managed to inject a `<script src="https://evil…">`, the browser would refuse to load it.
>>> 17
`nosniff`: the browser must trust the declared content type and not guess. Otherwise a text file could be "guessed" into a script.
>>> 18
When following a link to another site, send only the site's name, not the full address (which could contain ids).
>>> 19
Older way of forbidding frames (for browsers that do not understand `frame-ancestors`). This stops **click-jacking**: a hostile site placing EduMate invisibly over its own buttons.
>>> 21-26
Every `/api/...` request goes to `http://backend:8080`. Inside Docker's network, `backend` is the backend container's name. The three `proxy_set_header` lines pass along the original host name, the visitor's IP address (`X-Forwarded-For`) and whether they used http or https.
>>> 29-32
Everything else: send the requested file if it exists (for example `/assets/index-3f2a.js`); otherwise send `index.html`. This is needed for a single-page app. If someone opens `/hall-ticket` directly or presses refresh, there is no file with that name, so nginx sends `index.html`, and React Router shows the hall-ticket page.
